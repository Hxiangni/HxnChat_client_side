# 登录页浅色高级感视觉改版与注册表单改造

## 需求说明

对 HxnChat 登录对话框（`logindialog`）进行一次整体视觉升级 + 注册表单内容改造，保持既有滑动交互逻辑不变。

### 左侧（粉色滑块欢迎区）

- 滑块欢迎卡改造成「微信式身份卡」：**居中大圆头像，头像正下方一行用户名（即上次登录的用户名）**，用户名下方一句小字欢迎语，整体大面积留白、简约优雅、有设计高级感。
- 用户名当前无真实数据来源：先用一个临时演示常量（如 `HxnChat 用户`）保证可见，并保留 `TODO`：后续从「最近登录/记住我」配置读取真实用户名与头像路径。
- 头像：上次登录用户头像，无则显示浅色默认软件 logo（`makeRoundAvatar()` 白色细描边圆 + 内部浅粉默认 logo，白字「H」），保留 TODO 供后续替换。
- 滑块视觉元素自上而下：小号欢迎 overline → 圆头像 → 用户名（主视觉，白粗 20~22px）→ 小字副文 → 切换胶囊按钮。
- 滑块下方暗藏的**注册表单**字段改为：用户名 → 邮箱 → 验证码行（验证码输入框 + 「获取验证码」小按钮**同行紧凑排布**）→ 密码 → 确认密码 → 「注 册」主按钮 → 「已有账号？去登录」文字链接，布局在 520 高度内合理美观不拥挤。

### 右侧（登录表单）

- 标题改为「账号登录」，避免与左侧欢迎语重复；账号 + 密码 + 「登 录」主按钮 + 「没有账号？去注册 →」文字链接。
- 鼠标悬停时「去注册」文字、登录/注册主按钮、获取验证码按钮颜色**加深**；输入框聚焦时边框/底色变深变色。

### 配色基调

- 不要艳丽：**浅粉 + 浅蓝 + 白**，简约浅色高级感。
- **粉蓝分侧呼应**：左（注册/滑块区）粉系、右（登录区）蓝系——注册主按钮浅粉、登录主按钮浅蓝，两侧文字链接各自呼应粉/蓝，hover 时加深。

## 交付成果

- 改造后首次运行：白色圆角卡片（带柔和投影）内，左侧浅粉渐变欢迎卡自上而下呈现「欢迎回来 / 圆头像 / 用户名(上次登录) / 一句小字 / 白色胶囊切换按钮」，右侧登录表单（浅蓝按钮）。
- 点击「去注册」滑块滑至右侧露出注册表单（含邮箱与获取验证码），点「去登录」滑回，滑块文案/用户名随状态同步翻转。
- 所有按钮/链接 hover 加深、输入框 focus 变深变色，整体观感浅色、柔和、清爽、微信式亲切。

## 技术栈

- Qt 6 Widgets + C++（Qt 6.11.1 / MSVC2022 / CMake，沿用工程现状），UI 全部由代码（QSS + 布局）构建，不引入新依赖、不新建 qrc/资源。

## 实现思路

- 主要修改点集中在 `logindialog.cpp` 的 `initUI()`：**整块替换全局 QSS 字符串**（浅色粉蓝分侧配色）、重排注册面板控件、重做滑块欢迎卡（头像+用户名）、微调登录面板；`logindialog.h` 仅追加一个滑块用户名成员 `QLabel *sliderUser_ = nullptr;`。
- 用 QSS 后代选择器区分「同类型控件按所在面板着色」：`#registerPanel QLineEdit` / `#loginPanel QLineEdit`、`#registerPanel QLineEdit:focus` / `#loginPanel QLineEdit:focus`、主按钮 `#btnLogin`(蓝) 与 `#btnRegister`(粉) 独立规则。
- hover/pressed/focus 全用 QSS 伪状态实现，无 C++ 事件（QSS 无 transition，即时变色；邻近浅色观感柔和可接受）。
- 卡片「高级感」用 `QGraphicsDropShadowEffect`（浅紫灰、低透明度、大模糊、小偏移），在 card 创建后设置（父对象管理生命周期；cpp include `<QGraphicsDropShadowEffect>`）。
- 兼容性：保留既有 objectName（card/registerPanel/loginPanel/slider/sliderTitle/sliderDesc/switchBtn/textLink/titleLabel）与 connect 链路不变；`slideTo()` 只改其中文案翻转的那几行，使其覆盖新增的用户名行，不重写动画逻辑。

## 执行细节（防回归）

- 高度预算：窗口内容区 520；注册面板 6 个输入型控件（用户名/邮箱/验证码行/密码/确认密码）。用 `setContentsMargins` 收窄到约 (30,28,30,20)、`setSpacing(9~10)`、输入框 `setFixedHeight(42)`、验证码行 QHBoxLayout 总宽约 320（输入框弹性 + 获取验证码小按钮固定宽约 100~110）。
- 颜色在 QSS 注释里分组标注「粉系(左) / 蓝系(右) / 中性」，后续调色只改一处。
- 滑块浅粉渐变两处需同步降饱和：#slider QSS 背景 与 `makeRoundAvatar()` 默认 logo 填充色。
- 「获取验证码」按钮本轮仅做 UI（objectName `btnCode`，含 hover/pressed），真实发码逻辑留待后端。
- 登录面板标题由「欢迎回来」改为「账号登录」。
- `logindialog.h`：新增 `QLabel *sliderUser_ = nullptr;`（滑块用户名，供 slideTo 翻转/后续填充真实用户名）。其余无新增。

## 关键实现约定（滑块欢迎卡文案与翻转）

- 滑块登录态（盖左半边、登录可见）：小号 overline「欢 迎 回 来」（`sliderTitle_`，白 ~85%，14px 居中）；圆头像 116px；`sliderUser_` 白粗 22px 显示用户名（占位常量 + TODO）；`sliderDesc_` 白 ~70% 13px 如「老朋友，继续我们的对话吧」；胶囊「没有账号？去注册」。
- 滑到注册态（盖右半边、注册可见）时 `slideTo()` 翻转为：overline「加 入 HxnChat」；`sliderUser_` 显示「注册新账号」；desc「创建账号，开启新的对话」；胶囊「已有账号？去登录」。回到登录态再翻回。
- 主按钮：`#btnLogin` 浅蓝渐变、`#btnRegister` 浅粉渐变，白字、圆角、hover 加深、pressed 更深。
- 文字链接：登录侧 `#loginPanel #textLink` 蓝字、注册侧 `#registerPanel #textLink` 粉字，hover 各自加深。
- 输入框：中性极浅粉白底，focus 白底 + 分侧边框（左侧粉/右侧蓝）加深；placeholder 柔和灰。
- 头像/用户名文字区大面积留白，装饰圆点减至 1~2 个且高透明或移除。

## 设计风格

「浅色高级感」：白卡片 + 极浅粉背景渐变 + 柔和低透明度投影，圆角 22~28px，大量留白；左右粉蓝分侧呼应形成克制的色彩对话，微信式身份卡亲切感（头像+用户名），交互反馈（hover 加深、focus 变色）清晰不喧闹。

## 页面区块规划（单页对话框）

1. 白卡片容器：圆角 24、极淡投影、860×520 居中；
2. 左侧粉色滑块欢迎卡（粉系）：小号欢迎 overline + 白色圆头像（默认浅粉 logo）+ **用户名（上次登录，微信式主视觉）** + 一句小字 + 白色描边胶囊；
3. 右侧登录表单（蓝系）：标题「账号登录」+ 账号/密码输入框 + 浅蓝「登 录」按钮 + 蓝色「没有账号？去注册」链接；
4. 暗藏注册表单（粉系，滑块滑开后显现）：用户名/邮箱/验证码行（「获取验证码」浅粉小按钮同行）/密码/确认密码 + 浅粉「注 册」按钮 + 粉色「已有账号？去登录」链接。

## 交互细节

- 主按钮/获取验证码/文字链接：hover 加深一档、pressed 再加深一档；
- 输入框 hover 轻微边框提示，focus 白底 + 所属侧（粉/蓝）边框与底色加深；
- 滑块滑动沿用现有 slideTo() 动画，仅文案翻转逻辑覆盖新用户名行。
